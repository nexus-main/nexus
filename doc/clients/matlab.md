# Matlab client

Matlab support is limited and currently provided through repository samples rather than a separately published package.

- [Load data into Matlab](https://github.com/nexus-main/nexus/blob/dev/samples/matlab/sample_load.m)
- [Export data from Matlab](https://github.com/nexus-main/nexus/blob/dev/samples/matlab/sample_export.m)

Use the Matlab examples when Matlab is the target analysis environment. For larger integrations, prefer the REST API, Python client, C# client, or TypeScript client where possible.
